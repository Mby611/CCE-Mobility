# Paper Figures and Tables

`method.png` is a raster export of the method figure supplied with the paper, with the blank outer margins cropped for the README. `motivation.png` is the authors' supplied optional motivation image and is not displayed in the README. These figures illustrate the method, not an additional experiment.

The table manifest locks the numeric transcription in both READMEs to the supplied manuscript. It does not certify that a fresh run reproduces those numbers or that unpublished historical traces are available. Source PDF hashes identify the manuscript used for transcription without redistributing the full submission.
